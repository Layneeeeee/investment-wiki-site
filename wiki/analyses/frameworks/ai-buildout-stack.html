Analysis: AI Buildout 12-Layer Stack Framework

核心框架：AI 基础设施的建造成远不止 GPU/芯片层。从应用到矿产完整跨越 12 层，每层都有独立的供给约束和竞争动态。投资机会在于识别市场忽略的 bottleneck 层——而非所有人都盯着的同一层。

来源：2026-06-08—ren—ai-buildout-twelve-floors (Ren, Substack)

状态：轻框架，逐步填充。本版为首次全层 mapping，基于 wiki 知识库 + web research。

完整堆栈

Layer  1:  Application       ← AI 应用层（SaaS, Agent 平台）
Layer  2:  Model             ← 基础模型（GPT, Claude, Gemini, DeepSeek）
Layer  3:  Framework         ← 训练/推理框架（vLLM, TensorRT, Dynamo）
Layer  4:  Compute           ← GPU/ASIC/TPU
Layer  5:  Networking        ← 网络互联（交换机, NIC, 光互联）
Layer  6:  Memory            ← HBM, DRAM, NAND
Layer  7:  Interconnect      ← 芯片间/机架内互联光学化
Layer  8:  Substrate         ← 衬底/基板（InP, SiPh, EML）
Layer  9:  Equipment         ← 半导体设备
Layer 10:  Test/Reliability  ← 老化测试/可靠性验证
Layer 11:  Packaging         ← 先进封装（CoWoS, CPO）
Layer 12:  Critical Minerals ← 镓、锗、铟等关键原材料

跨层系统：Power · Thermal · Security · Edge AI

层的经济学特征

不同层的投资经济学完全不同。框架的价值在于区分：

类型特征示例层投资含义
Bottleneck 层供给刚性 + 需求爆发 + 短期不可替代L6 Memory, L7 Interconnect, L8 Substrate, L10 Test定价权、溢价、优先扩产
赋能层技术壁垒高但供给可扩L4 Compute, L9 Equipment龙头优势，但需跟踪产能
商品化层差异化低、价格竞争L1 Application (大部分), L3 Framework (开源)选龙头或做多周期性底部
跨层系统贯穿所有层的基础设施Power, Thermal, Security总量逻辑，受总建造成本驱动

信号使用说明

  1. 进入条件：该层 ≥2 个 🟢 信号同时出现 → 考虑配置
  2. 退出条件：该层 ≥2 个 🔴 信号出现 → 考虑减仓
  3. Bottleneck rotation play：当一层出现 🔴 退出信号时，资金可能流向下一层——提前布局下一层的 🟢 信号
  4. 当前最大机会层（最多 🟢 + 最少 🔴）：L8 InP Substrate, L10 Test/Reliability, L7 Interconnect
  5. 当前最危险层（最多 🔴）：L6 Memory（周期峰值信号已确认）

跨层关联矩阵

层间 bottleneck 传导路径：

CoWoS (L11) 瓶颈缓解 → HBM (L6) 需求加速 → InP/EML (L8) 供给压力
电力 (Power) 约束 → 数据中心选址限制 → 光学互联距离需求变化
模型层 (L2) 成本下降 → 推理量暴增 → 推理芯片 (L3/L4) 需求 + 存储 (L6) 需求

Key insight：当一个层 bottleneck 缓解时，资金通常流向下一个紧的层。CoWoS 扩产后 → HBM 成为瓶颈 → HBM 扩产中 → Interconnect/InP 将成为下一个。当前 cycle 位置：L6 (HBM) 正在缓解中，L8 (InP/EML) 正在收紧。

框架局限性

  1. 当前仅 1 个 direct source——层映射来自 Ren 框架 + web research 补充，非单一权威来源
  2. 公司跨层——NVDA 横跨 L4+L5+L6，GOOGL 横跨 L2+L4+L5，单层映射过度简化
  3. 层间替代性未体现——电互联（铜缆）vs 光互联在某些场景可相互替代
  4. Bottleneck 动态性——瓶颈随时间在不同层间移动，静态 snapshot 可能误导
  5. 未量化——没有每层的 TAM 或供给缺口数据，目前是定性组织工具
