Analysis: AI Stack as Modular Middle — Layer-by-Layer Value Capture

将”Everything is Computer”框架（everything-is-computer-framework）应用于 AI 价值链。针对每一层：其在智能手机蓝图中的对应物、价值捕获动态、关键公司以及价值迁移方向。

Layer 0: Physical Infrastructure (Data Centers, Power)

Smartphone analog: 原材料 + 制造（硅晶圆、TSMC）

Current state: 数据中心系统支出在 2025 年约 500B，预计2030年达 1.5T（2026-03-18—ark-ai—big-ideas-2026）。超大规模云商 2026 年资本支出 >$500B。能源约束正成为数据中心建设的刚性瓶颈。

Value capture dynamic: 类大宗商品。电力公用事业和数据中心 REITs 受益于规模增长，但没有定价权——容量是可替代的。唯一的差异化因素是地理位置（廉价电力、低用户延迟）。

Key question: 电力约束是否会为早期数据中心站点创造”抢地”护城河，还是能源市场会自我调整并使接入商品化？

Verdict: 低价值捕获，必要但非充分条件。

Layer 1: AI Compute (GPU / Inference Silicon)

Smartphone analog: Qualcomm Snapdragon、ARM 核心——每个设备都需要的关键芯片模块，受益于 TSMC 的工艺 compounding

Current state: NVIDIA 拥有 ~85% GPU 市场份额，毛利率约 75%。Grace Blackwell (GB200) 在大模型推理领域领先。AMD MI355X 在小模型推理方面具有竞争力。Google TPU v7 和 AWS Helios 正在开发中。MatX 正在构建定制推理芯片（matx）。每 TCO 美元产生的 token 数正成为关键竞争指标。（2026-03-18—ark-ai—big-ideas-2026, 2026-04-29—dwarkesh-patel—reiner-pope-math-behind-llms）

Value capture dynamic: 这是 Qualcomm/ARM 层——具有最强规模经济和工艺 compounding 的模块。NVIDIA 受益于：

  1. CUDA 护城河：锁定开发者的软件生态——类似于 Qualcomm 的 modem IP 不可替代
  2. Scale-up domain compounding：Hopper (8 GPUs) → Blackwell (72) → Rubin (~500+)——由 MoE all-to-all 通信驱动的更大规模 scale-up domain（2026-04-29—dwarkesh-patel—reiner-pope-math-behind-llms）
  3. Wright’s Law：每一代都在每美元提供更多 FLOPs，但进入壁垒在上升，因为工艺知识在持续积累

Key question: 定制 ASIC（MatX、传闻中的 OpenAI 芯片、Google TPU）能否打破 NVIDIA 的垄断？智能手机类比表明最终可以（Apple A 系列、Samsung Exynos），但仅限于垂直整合的玩家。

Verdict: 当前价值捕获最高。 在此框架下，NVIDIA 是 AI 栈中定位最佳的公司——每个 AI 工作负载都依赖的模块供应商，以工艺 compounding 作为结构性护城河。

Layer 2: Foundation Models (the Modular Middle)

Smartphone analog: Android/iOS——介于硬件和应用之间的操作系统。在智能手机世界中，OS 所有者（Apple、Google）通过平台控制捕获了巨大价值。

Current state: OpenAI GPT-5.5 在 Artificial Analysis Intelligence Index 上得分 60%，领先所有前沿模型，性能在 Anthropic 未发布的 Mythos 范围内——但定价为 11.30/Mtokens（是上一代的2倍，对比Opus4.7的10/M）。基准测试中使用的 token 数比 Opus 4.7 少约 1/3。（2026-04-27—ark—disrupt-newsletter-psychedelics-tesla-openai）

与此同时：DeepSeek-v4（1.6T 参数、1M 上下文、MIT 许可证）、Kimi-K2.6（1T 参数、384 experts、AI Index 上 #1 开源模型）、Qwen3.6-27B（Apache 2.0）——开源模型正接近前沿能力。（2026-04-27—alpha-signal—deepseek-v4-kimi-k26）

Anthropic 的”model eats the harness”动态：每一代新模型都允许移除 prompt 干预和 UI 辅助——产品复杂性随着模型能力的提升而降低。（2026-04-23—lenny-rachitsky—cat-wu-anthropic-product-velocity）

Value capture dynamic: 这是关键战场。该框架认为 modular middle 可以在以下条件下捕获不成比例的价值：

  1. 差异化持续存在：专有和开源模型之间的前沿差距持续存在 → 定价权（OpenAI 将 GPT-5.5 价格翻倍）
  2. 商品化胜出：开源匹配前沿 → 利润率压缩至零，价值迁移至计算层（Layer 1）或应用层（Layer 3）

“model eats the harness”动态实际上暗示商品化是长期轨迹——随着模型变得更好，模型特定集成工作的价值下降。这正是智能手机 OS 发生的情况：Android 将 OS 层商品化，价值迁移到建立在之上的 Google 服务（搜索、广告、云）。

Key tension: 前沿实验室在训练上投入巨额资本支出。如果商品化胜出，这些资本支出无法通过模型定价收回。推理成本回收的压力意味着前沿实验室必须不断提价（如 OpenAI 对 GPT-5.5 的做法）或寻找更高利润的应用（Codex、企业 agents）。

Verdict: 不确定性最高 / 潜力最大。 如果前沿护城河持续，这是最好的层——具有强定价权的平台控制。如果商品化继续，这一层将成为成本中心而非利润中心。

Layer 3: Agent Platforms (System Integration)

Smartphone analog: OEM（Apple、Samsung、Xiaomi）——将模块组合成成品的系统集成商。在智能手机世界中，大多数 OEM 被挤压（Samsung 的手机利润率很低），除了同时拥有 OS 和芯片的 Apple。

Current state: OpenAI 发布 workspace agents（通过 ChatGPT/Slack 的共享云 agents）、ChatGPT Images 2.0、Codex 升级。Codex 活跃用户 3M→4M 在约 2 周内（自 2026 年 1 月以来增长约 20 倍，从 ~0.2M）。（2026-04-27—ark—disrupt-newsletter-psychedelics-tesla-openai）

Anthropic 产品路线图：单任务 → 多任务（6 个并发）→ 50-100+ 远程运行的 agent 集群。Claude Code 在内部被用作 PR merge 的必要门控。（2026-04-23—lenny-rachitsky—cat-wu-anthropic-product-velocity）

AI agent 任务时长在 2025 年增长了 5 倍（6 分钟 → 31 分钟）。AI 促进的商业交易预计将从在线消费的 2% 增长到 2030 年的 25%（>$8T）。（2026-03-18—ark-ai—big-ideas-2026）

Value capture dynamic: 在智能手机栈中，不拥有自己 OS 或芯片的 OEM 被挤压至 <5% 的利润率。例外情况证实了规则：

  • Apple：拥有 OS (iOS) + 芯片 (A 系列) + 分销 (App Store) → 捕获了行业大部分利润
  • Xiaomi：以接近成本的价格销售硬件，通过服务赚钱——本质上是一种分销策略

对于 AI agent 平台，该框架预测：

  1. 拥有自己基础模型的平台（OpenAI、Anthropic）具有结构性优势——它们可以优化全栈并在两个层面捕获价值
  2. 垂直整合的物理世界公司（Tesla 拥有 Dojo + FSD + Optimus、Physical Intelligence 拥有 π₀ + RECAP + 硬件）是 Apple 的类比——拥有模型、推理和物理载体
  3. 纯 agent 中间件（建立在调用他人模型的 API 之上的公司）面临利润率压缩，因为模型改进并吸收了 agent 功能

Key question: Agent 平台将由模型所有者（OpenAI、Anthropic）主导，还是由分销所有者（Microsoft、Google、Salesforce）主导？

Verdict: 如果你拥有模型 + 分销，则赢家通吃。 纯 agent 公司面临结构性利润率压力，因为”model eats the harness”。

Layer 4: Vertical AI Applications

Smartphone analog: App Store 上的应用（Instagram、Uber、Spotify）——非常有价值的独立业务，但依赖于平台规则并受制于平台税（30% App Store 抽成）。

Current state: AI-native 初创公司达到前所未有的收入规模——Cursor 1BARR（成立于2022年）、Harvey100M（法律）、OpenEvidence 100M（医疗）、Sierra100M（客服）。成立 3 年的公司年同比增长 >1,000% ARR。（2026-03-18—ark-ai—big-ideas-2026）

Value capture dynamic: 三种情景：

  1. API 的薄包装 → 低护城河、高流失率、利润率压缩（随着模型改进和平台所有者扩展到应用）
  2. 专有数据飞轮（Cursor 的代码库、Harvey 的法律文档）→ 高转换成本、可防御、垂直领域赢家通吃
  3. 分销护城河（OpenEvidence 的医疗工作流集成）→ 高留存率、中等定价权

智能手机类比表明，大多数纯应用最终会失去对平台的定价权。但垂直 SaaS 历史上比消费应用更持久——而且 AI 垂直应用具有消费应用所缺乏的专有数据优势。

Key question: 基础模型所有者是否会构建竞争性的垂直应用（OpenAI Codex vs Cursor），还是保持平台层提供商的角色？智能手机历史表明，平台最终会进入最有价值的应用类别。

Verdict: 高方差。 具有专有数据护城河的垂直 AI（Harvey、Cursor）可以成为伟大的业务。薄包装 AI 应用在模型改进时面临结构性消亡。

Layer 5: Physical World AI (Next Domain)

Smartphone analog: 相同的电子工业栈正在部署到新的物理形态因素中——“万物皆是带 X 的智能手机”的论点。

Current state: Physical world AI 基础能力正在同步成熟——五个基础能力使机器人技术、自主科学和新接口进入自己的 scaling regime。机器人技术的价值正从机械系统迁移到模型、训练基础设施和数据飞轮。（2026-04-15—a16z—hsu-frontier-systems-physical-world）

Tesla：Robotaxi 在达拉斯/休斯顿推出，Cybercab 投入生产，Optimus 正在开发中。（2026-04-27—ark—disrupt-newsletter-psychedelics-tesla-openai）

Physical Intelligence：RECAP RL 后训练实现 2 倍吞吐量，最困难任务失败率降低 50%+。π*₀.₆ 可折叠 50+ 种新衣物类型、组装盒子、制作浓缩咖啡——自主运行数小时。（2026-04-15—a16z—hsu-frontier-systems-physical-world）

Value capture dynamic: 这是该框架最重要的考验。该框架预测：

  1. 垂直整合的公司（拥有模型 + 硬件 + 推理）将捕获最大价值——Tesla 是最清晰的类比
  2. Physical world 基础模型公司（Physical Intelligence、Generalist）是新的”modular middle”——如果它们胜出，将成为机器人领域的 Qualcomm
  3. 不拥有 AI 栈的硬件优先公司面临与 Android 手机制造商相同的 OEM 挤压

Key insight: “创新流逆转”意味着 physical world AI 受益于在消费/软件 AI 层开发的能力——模型变得更好，而 physical world 公司无需进行基础训练。这对 Tesla、Physical Intelligence 等公司来说是一种结构性补贴。

Verdict: 最早阶段、最高上行空间。 该框架表明垂直整合的模型所有者将胜出，但该领域还为时过早，难以定论。

The prediction: 未来 3-5 年，价值将迁移：

  • FROM: 通用应用层 AI（薄包装）
  • TO: 拥有模型 + 计算 + 分销的垂直整合玩家（OpenAI、Tesla、Anthropic）
  • AND: 规模经济持续的模块层（NVIDIA）
  • WITH: Physical world AI 作为下一前沿，同样的动态将在此上演

Key monitor: 最重要的单一数据点是前沿模型与开源模型之间的价格差距。如果差距扩大，modular middle（基础模型公司）捕获平台级价值。如果差距缩小，价值迁移至计算层（NVIDIA）和垂直整合的应用。

Benedict Evans 商品化论据 (2026-06-01)

Evans 以电信业为类比：全球移动行业收入 ~$1T/年，数据消费自 2010 年增长 1500-2000x，但”股票 25 年没涨”——这是低利润大宗商品基础设施的经典特征。他认为模型 Lab 面临类似命运：无网络效应、无实质差异化、产品商品化。若此框架正确，则 commoditization 路径（Scenario 2）的概率高于市场当前定价。(2026-06-01—benedict-evans—ai-eating-the-world)

Claim

“Everything is Computer”模块化栈框架预测 AI 价值链中价值的集中方向：推理基础设施（模块层）和垂直整合的 agent 平台将捕获不成比例的价值，而纯应用层 AI 面临利润率压缩。

Evidence For

  • NVIDIA GPU 模块层定价权持续（毛利率 ~75%），CUDA 护城河验证”模块层价值捕获”（2026-03-18—ark-ai—big-ideas-2026）
  • 前沿模型 vs 开源差距缩小：DeepSeek-v4、Kimi-K2.6 接近前沿性能→“model eats the harness”动态验证（2026-04-27—alpha-signal—deepseek-v4-kimi-k26）
  • OpenAI GPT-5.5 定价为上一代 2 倍→差异化持续时模型层有定价权（2026-04-27—ark—disrupt-newsletter-psychedelics-tesla-openai）
  • OpenClaw 将 Claude Opus 和 Codex 视为可互换商品→agent 框架捕获关系，模型可插拔（2026-03-31—lenny-rachitsky—claire-vo-openclaw-personal-ai-agent）
  • SaaS 从 per-seat 向 consumption 转型→价值从应用使用向基础设施消费转移（2026-05-01—jamin-ball—death-of-per-seat-pricing）
  • Ambarella 边缘 AI SoC 模块层价值捕获验证（2026-05-04—gaetano—ambarella-edge-ai）

Evidence Against

  • 智能手机类比可能不成立：AI 是通用技术，栈更流动
  • 应用层公司可能通过专有数据飞轮构建持久护城河（Cursor、Harvey）
  • NVIDIA GPU 主导地位可能被 ASIC（推理专用芯片）颠覆
  • 开源模型可能阻止单一公司捕获”modular middle”
  • AI 中的”可信垂直整合威胁”需要巨额资本，可能失败

Current Judgment

框架逻辑成立但尚未到可下注阶段 → watch。核心矛盾（差异化 vs 商品化）未解决前，此框架更适合作为分析透镜而非投资 thesis。
