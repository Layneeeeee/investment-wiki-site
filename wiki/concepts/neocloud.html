Neocloud（AI 专用 GPU 云）

Definition

Neocloud（新云）是指专门为 AI 工作负载提供 GPU 算力租赁服务的云基础设施提供商。与 AWS/Azure/GCP 等超大规模通用云不同，neocloud 的核心特征是：

  • GPU-only：不提供通用计算、存储、数据库等云服务，只提供 GPU 算力
  • 专业化运营：通过高度聚焦的 GPU 集群部署运维效率，实现比超大规模云商更低的 GPU 租赁价格
  • 高杠杆：以债务融资为主（典型 D/E >5x），快速扩张 GPU 容量
  • 灵活合同：提供预留合同与按需实例，部分合同含提前解约条款

Why It Matters

Neocloud 代表了 AI 基础设施投资中一个全新的资产类别——介于超大规模云商（自有芯片、全球网络）和纯粹的数据中心 REIT 之间。对于投资者：

  1. AI 算力短缺的直接受益者：AI 模型训练和推理对 GPU 的需求呈指数级增长，neocloud 是纯 GPU 算力的 “pure play”
  2. IPP 式市场结构：类比美国电力 deregulation 后独立发电厂（IPP）的兴起——少数大型 neocloud + 长尾小型运营商，PE 资本深度参与
  3. 极端规模下的价值创造：Jamin Ball 估算 150GW 建设 × 90b/GW=13.5Tn 潜在企业价值创造（2026-05-22—jamin-ball—neocloud-boom）
  4. 估值基准作用：CoreWeave ~6x NTM rev / ~10x EBITDA 被用作整个 AI 基础设施赛道的估值锚点

IPP 类比（独立发电厂）

Jamin Ball 提出的核心框架：neocloud 市场结构演化将类似美国电力 deregulation 后的 IPP 市场：

阶段电力市场Neocloud 市场
前 deregulation垂直整合公用事业（发电+传输+配电）超大规模云商（自研芯片+自建 GPU 集群+自用）
后 deregulation独立发电厂（只发电，不拥有电网）Neocloud（只提供 GPU 算力，不拥有 AI 模型/应用层）
资本结构PE/基础设施基金持有PE/债务融资为主，高杠杆
玩家结构少数大型 IPP + 长尾单站运营商预计类似：CoreWeave/Nebius/IREN + 小型 neocloud

核心洞察：当 AI 算力需求超过超大规模云商的自建能力时，neocloud 填补了”商户市场”（merchant market）的空白——为无法获得超大规模云商 GPU 配额的公司提供算力。

GPU 第二生命经济（2026-05-30 新增）

Jamin Ball 在 2026-05-29 的 Clouded Judgement 中提出了 GPU 第二生命（Second Life of a GPU） 框架（2026-05-29—jamin-ball—gpu-second-life），这是一个对 neocloud 经济模型有重大影响的新论点：

核心逻辑

Neocloud 通过 project-level debt 融资单个数据中心，债务期限与单一承购方（offtaker）的 4-5 年合同匹配。在合同期内，债务分期偿还。合同到期后：

  • 债务已清偿 → 无利息支出
  • GPU 芯片仍有实用价值（特别是推理工作负载）
  • Neocloud 可以以大幅折扣的价格重新签约（recontract）同一站点用于推理
  • 无利息成本 + 推理负载的利润率可以”skyrocket”

三种业务模式

类型描述定价能力
Bare Metal仅提供 GPU + 网络 + 电力，客户自带调度/存储/软件栈低
Managed KubernetesBare metal + 编排层管理（调度、节点故障、网络配置）中
Full Cloud类似 AWS/Azure/GCP 完整体验（存储、数据库、推理端点、可观测性）高

关键条件

  • 前提：芯片物理寿命 > 合同期限（4-5 年）
  • H100/B200/GB200 在合同期满后仍适用于推理负载（不需要前沿训练芯片）
  • 推理需求持续爆炸 → 有充足的第二生命芯片需求
  • 公司购买而非租赁芯片（购买保留残值权利）

含义

  • 当前 neocloud 估值（EV/GW 框架）未包含 GPU 残值期权价值
  • 如果芯片保留 30-50% 推理效用，neocloud 的真实盈利潜力被低估
  • CoreWeave（购买芯片策略）相比租赁芯片的同行更受益
  • 但核心实证问题：GPU 的实际折旧曲线是什么？5 年后推理质量受芯片退化影响几何？

关键验证案例

SpaceX/xAI/Anthropic 交易：Anthropic 以 15b/年向SpaceX租用Colossus算力（约500MW），单合同接近SpaceX23年积累的18.7b 年收入。验证了 neocloud 模式在极端规模下的可行性（2026-05-22—jamin-ball—neocloud-boom）。

建设规模

  • OpenAI 目标：2030 年 30GW
  • 行业估算：2030 年新增 ~150GW AI 数据中心容量
  • 每 GW 成本：~$50b（70% 芯片，20% 基础设施，5% 冷却，5% 土地）
  • 总支出：~7.5Tn（ 1.7Tn/年，约美国 GDP 5%）
  • 历史对比：1880 年代美国铁路约 GDP 6%，2000 年代初电信约 1.2%

Key Properties

  • 先发规模优势：最早大规模部署 H100/H200/B200 的云之一，拥有 NVIDIA 优先配额
  • 大客户锁定：长期合同（Meta 至 2032 年、Anthropic、Microsoft、OpenAI）提供收入能见度
  • 高债务杠杆：典型 D/E 5x+，利率高位环境下展期成本高
  • commodity 定价风险：GPU 算力是 commodity，差异化低于芯片层
  • EV/GW 估值框架：$90b/GW 是当前市场隐含估值，但样本量极小（仅 3 家）

关键风险

风险描述严重程度
超大规模商竞争AWS Trainium、Google TPU 自研芯片减少对外部 GPU 云需求🔴
NVIDIA 自建租赁NVIDIA 可能绕过 neocloud 直接提供 GPU 租赁🔴
债务容量限制$24.9B+ 债务在高利率环境下的展期和融资能力🔴
GPU commodity 化无芯片层差异化，价格竞争压缩利润率🟡
客户集中度少数大客户占总收入比重高，解约条款（如 90-day out）带来收入波动🟡

Open Questions

Question

  • IPP 类比是否准确？Neocloud 真的能演化成”少数大型 + 长尾”结构，还是超大规模商自建最终主导？
  • Anthropic $15b/年 的 90-day out 条款——这是紧急定价还是 compute-constrained AI labs 的新常态？
  • 在 ~5% GDP 的 AI 基础设施支出下，哪个宏观约束（劳动力、电力、材料）最先成为瓶颈？
  • Neocloud 能否在 hyperscaler 自研芯片时代保持差异化，还是最终沦为 commodity GPU 的”批发转零售”中间商？
  • GPU 残值（Second Life）期权价值：GPU 的实用折旧曲线是什么？H100/B200 在 5 年后对推理负载还有多少实用价值？这个期权是否应该被纳入 neocloud 估值？
