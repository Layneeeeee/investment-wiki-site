Everything is Computer Framework

Definition

万物皆计算机框架（Everything is Computer Framework）是一个分析技术价值链的框架，基于以下洞察：智能手机蓝图（计算 + 电力 + 感知 + 连接 + 软件）已成为通用模板，价值在规模经济最陡峭的堆栈层中累积。该框架预测了模块化使新进入者成为可能，同时不同层级在位者获得或失去定价权时，价值如何在各层之间迁移。

源自 Ryan McEntush 的 a16z 文章 “Everything is Computer”（2026-01-07—a16z—mcentush-everything-is-computer），在此扩展为通用的投资分析透镜。

Why It Matters

该框架提供了一种结构化的方式来回答科技投资中最重要的问题：“价值在堆栈的哪个层级集中，下一个将迁移到哪里？”

在模块化堆栈中：

  • 模块层（module layer，跨多个终端产品共享的组件/子系统）受益于规模经济最多——成本随产量复合下降，创造结构性护城河
  • 系统集成层（system integration layer，OEMs）面临利润率压缩，因为模块标准化后竞争转向品牌和分销
  • 应用层（application layer）在网络效应或数据飞轮作用下可能赢家通吃，但持续面临平台入侵的威胁

应用到 AI，框架预测：

  1. AI 计算（GPU）是模块层——规模经济和工艺复合创造持久优势（NVIDIA）
  2. Foundation models 是模块化中间层——赢家动态取决于差异化是持久的还是商品化胜出
  3. AI agents 是应用层——在拥有强大分销护城河的垂直领域赢家通吃
  4. 物理世界 AI（机器人、自主科学）是同一堆栈重新部署的下一个领域——“带轮子/螺旋桨/身体的 AI agents”

Key Properties

  • 规模追求（Scale-seeking）：价值流向单位成本随产量下降最快的层级——在电子领域是模块（芯片），在 AI 领域是推理
  • 模块化作为价值毁灭者：当一个层级变得模块化/标准化时，利润率压缩，价值迁移到相邻层级（PC OEMs 的价值流失给了 Microsoft/Intel）
  • 可信的垂直整合威胁（Credible vertical integration threat）：威胁向后整合进模块的能力约束了供应商——SpaceX 这样做，Apple 这样做，很少有其他公司能做到
  • 创新流向逆转（Innovation flow reversal）：在电子工业时代，创新从消费者→国防流动（而非反过来），意味着消费级市场规模资助了后来服务于高价值应用的能力发展
  • 工艺复合（Process compounding）：制造工艺随累计产量提升（Wright’s Law）——制造最多产品的公司学习最快，与设计优势无关

Open Questions

The framework predicts value migrates to the layer with steepest Wright's Law. In AI, is that inference silicon (NVIDIA), inference serving (providers), or model architecture (better algorithms per FLOP)? All three have declining costs — which compounds fastest?

Does the "credible vertical integration threat" apply in AI? OpenAI is reportedly building chips — does this discipline NVIDIA's pricing, or is chip development too capital-intensive for the threat to be credible?
